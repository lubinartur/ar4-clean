# AIR4 — V3 SNAPSHOT (STABLE)

## Status
- Version: AIR4 v3.0
- State: STABLE
- Core: v2.0 Foundation (LOCKED)
- Nature: thinking-in-time layer

## What V3 IS
AIR4 V3 extends thinking from "within a session" to "across time".
It observes repetitions, dynamics, and persistence of signals without:
- giving advice
- making conclusions for the user
- initiating actions without consent

V3 adds time-awareness, not intelligence inflation.

## Tracks Overview

### Track A — TIME
- Q3: Longitudinal memory (repeats across days)
- R3: Cross-session patterns
- Q3.2 / R3.2: Trend calculation (delta, direction, windows)
Characteristics:
- Read-only
- No interpretation
- No automatic surfacing without gates

### Track B — MEMORY AS OBJECTS
- S3: Pattern objects (id, confidence, decay, lifetime)
- T3: Aging & forgetting
- Manual promotion and status control
Patterns are objects, not text memories.

### Track C — USER AGENCY
- U3: User control layer
  - mute / unmute
  - defer / clear defer
  - allow_only (q3 / r3)
  - last-reference ("это")
User can override AIR4 logic at any time.

### Track D — META
- W3: Audit & self-explain
- X3: Competing hypotheses
AIR4 can explain *why* something was shown or suppressed.

## What V3 DOES NOT DO
- No agents
- No autonomous actions
- No advice
- No psychology
- No long-term goal planning
- No UI commitments

## Design Guarantees
- V2 core behavior unchanged
- All V3 logic is gated
- All decisions are auditable
- User always has final control

## Activation
- Controlled via AIR4_V3_ENABLED flag
- All advanced features are opt-in

## Snapshot Conclusion
AIR4 V3 is a completed layer that enables stable thinking across time
without sacrificing user agency or system integrity.
