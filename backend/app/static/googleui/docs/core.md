# AIR4 — Core

## Что такое AIR4
AIR4 — это локальный внешний мозг.
Он хранит контекст, продолжает мышление и помогает принимать решения.
AIR4 — не чат и не ассистент для вопросов-ответов.

## Для кого
Один power-user.
Человек, ведущий несколько сложных проектов, который использует AIR4 ежедневно
как рабочую среду для мышления и памяти.

## Главная ценность
1) Долговременная контекстная память.
2) Снижение когнитивной нагрузки за счёт вынесенного мышления.

## Базовые сценарии (ровно три)
1. Думать и решать  
   — диалог как форма мышления  
   — автоматическое сохранение выводов в память

2. Хранить знания  
   — ingest документов/заметок  
   — структурированная долговременная память

3. Возвращаться к контексту  
   — сессии, recall, резюме прошлых решений  
   — продолжение с того же места

## Что AIR4 не делает
- Не является облачным сервисом
- Не является универсальным ассистентом
- Не оптимизируется под массового пользователя
- Не приоритизирует “ответы”, а приоритизирует контекст

## Критерий принятия решений
Любая функция должна усиливать роль AIR4
как внешнего мозга для одного пользователя.
Если не усиливает — не добавляется.
